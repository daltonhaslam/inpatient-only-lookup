# Pass B, batch m02: codes for a second look

- 31390, 31395: the tracheostome made during total laryngectomy is not coded separately (treated as part of the Resection). Neck dissection is coded as Resection of neck lymphatics only. A true radical dissection could also add sternocleidomastoid/IJ resection codes. None of this changes the pre-MDC family.
- 31395: the flap varies (pedicled pectoralis = Transfer thorax muscle; free jejunum or radial forearm = Replacement pharynx plus donor-site Excision per B3.9). Free-flap donor-site laterality is shown as left only.
- 31725: non-OR (Extirpation of mucus, bronchoscopic). Groups medical. The principal dx (pneumonia vs acute respiratory failure) decides the family.
- 31760: Supplement with mesh (tracheobronchoplasty for malacia) vs plain Repair. Same family either way. A J39.8 dx choice for acquired tracheal stenosis/malacia is worth a coder's check.
- 31766: Resection of carina (163-165) vs Excision of carina (166-168) changes the family. I chose Resection for full carinal resection with neocarina.
- 31805: an iatrogenic intubation tear (J95.72 alternative) moves the case to 907-909.
- 32035, 32036: open Drainage of pleural cavity is non-OR in MS-DRG, so the case groups medical (177-179). Rib resection is access (B3.1b). Eloesser: I did not code the skin flap separately. If a coder adds a Transfer/flap code, the case would go surgical.
- 32150: open Extirpation of pleural cavity is non-OR, so the case groups medical (pneumothorax family with traumatic hemothorax dx). The alternative is Extirpation of pleura (0BCN/0BCP, OR) if the fibrin is described as stripped from the pleural surface.
- 32160: open cardiac massage mapped per the PCS index to Repair heart (02QA0ZZ). The principal dx in real cases is the arrest's cause, not I46.9. Low confidence.
- 32220, 32225, 32320: decortication coded as Extirpation of matter from pleura. The PCS index also allows Release of lung (0BNK/0BNL). Both are 163-165.
- 32442: sleeve pneumonectomy coded as lung + carina Resection. A partial tracheal Excision could also be argued. Same family.
- 32445: Resection of pleura is not a valid PCS value, so the pleura is coded as Excision. Diaphragm/pericardial patch Replacement codes are added only in set 3.
- 32486: the bronchial sleeve is coded as Excision of the main bronchus (a separate body part). Some coders treat it as part of the lobe Resection. Same family.
