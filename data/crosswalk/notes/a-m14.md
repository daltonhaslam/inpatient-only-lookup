# Pass A, batch m14: codes for a second look

- 27259: shortening osteotomy built as Excision + Reposition with fixation of the upper femur, plus the hip Reposition. The Excision code moves the case from 480-482 to 498/499. Coding the shortening as Reposition only would keep it in 480-482. Low confidence.
- 27282: PCS has no pubic symphysis joint and no pelvic-bone Fusion value, so this is built as Insertion of internal fixation + Supplement with autograft, pelvic bone. The principal dx (M25359, hip-region instability) is a stand-in. Low confidence.
- 27280: the device value (0SG704Z internal fixation vs 0SG707Z autograft) is a judgment call because B3.10c strictly covers vertebral joints only. The bilateral set (two codes) groups to 447/448, multi-level spinal fusion. That is real grouper behavior, but it sits a family above unilateral (450/451).
- 27295: body part for hip disarticulation is Femoral Region (0Y67/0Y68), by analogy with Shoulder Region for shoulder disarticulation. 0Y6C0Z1 (upper leg, high) is the competing choice. The dx drives the family: gangrene gives 239-241, osteomyelitis or tumor gives 474-476.
- 27187: approach assumed open, but prophylactic nailing is often done through stab incisions (0QH636Z, percutaneous). Same family either way.
- 27254: up to three Repositions (hip joint, acetabulum, upper femur). Whether the joint reduction gets its own code next to the fracture fixation is worth a coder's view.
- 59121 / 59130: used the newer Extraction value for ectopic products of conception (10D20ZZ) rather than Resection (10T20ZZ). Same family.
- 59120 / 59136: pregnancy removed with the organ or tissue is coded only as Resection of the tube/ovary or Excision of the uterus. No obstetrics-section code was added.
- 59350: coded alone, it groups to antepartum 817-819. In practice it usually comes with a cesarean delivery code, which would move the case to the cesarean family (783-785).
- 27185: pediatric procedure with almost no Medicare volume. The Perthes dx is a placeholder for the typical indication.
