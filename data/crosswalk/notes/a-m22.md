# Pass A, batch m22: codes for a second look

- 60600 — Correctly coded carotid body Resection (0GT6/0GT7) with carotid body tumor dx (D355; D446 and C755 behave the same) groups 981-983 "unrelated": the dx sits in MDC 1 and the 0G carotid body codes are not on the MDC 1 OR list. Grouper behavior, not a coding choice; Excision vs Resection does not change it.
- 60605 — Adding the internal carotid Excision moves the same tumor to 037-039. If the carotid segment is reconstructed with a graft, Replacement (03RK/03RL) would replace the Excision code (reconstruction is a separate CPT, so not included).
- 37617 — Low confidence on indication: ligation of aorta/iliacs spans infected graft, hemorrhage, aneurysm exclusion; family splits by vessel (aorta 268/269 vs iliacs 270-272).
- 35800 — I97.6x complication dx groups 907-909 (expected for post-procedural complication). Most of these returns to OR happen within the index stay, where this code would not drive the DRG.
- 53415 — Root choice: anastomotic Excision vs graft Supplement (+ buccal harvest per B3.9); both group 671/672.
- 53448 — Debridement in the infected field not coded (only if documented excisional). Root pair Removal + Insertion of artificial sphincter.
- 51940 — Bladder exstrophy is a pediatric operation; Repair vs Reposition of bladder judgment; Medicare volume negligible.
- Hip/knee revision grouper fix: no hip or knee codes in this batch; not applicable.
