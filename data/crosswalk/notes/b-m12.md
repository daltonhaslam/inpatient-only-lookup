# Pass B, batch m12: codes for a second look

- 47900: typical dx K9189 (post-cholecystectomy duct injury) groups to 981-983 (MDC 6 dx with a biliary OR procedure). Kept because it's the correct dx; S3613XA (traumatic) groups to 408-410. A coder might use K832/K838 as principal, which would group to MDC 7.
- 47800: Excision (stricture segment removed) vs Repair (divided duct rejoined). Both are listed; both group to 408-410.
- 48105: Excision (excisional necrosectomy) chosen over Extirpation of the pancreas. Same family either way.
- 48145: the pancreatic remnant-jejunum anastomosis is not coded, so it maps the same as 48140. Bypass 0F1D0ZB would be the alternative reading.
- 48150/48152 and 48153/48154: the with/without pancreatic anastomosis pairs map identically (anastomoses not coded). Pylorus-preserving variants use Excision of the duodenum (proximal cuff kept) and no gastric code.
- 48155: total pancreatectomy coded with duodenum, gallbladder, distal CBD ± spleen. Check whether reviewers expect the antrum (0DB60ZZ) too.
- 48520: PCS has no Bypass pancreas-to-stomach value, so cystogastrostomy = Drainage of pancreas. Cystoduodenostomy = Bypass pancreas to duodenum. Same family.
- 48547: coded as pyloric Occlusion + gastrojejunostomy Bypass (423-425). The plain label mentions pancreatic repair; if repair is documented, adding 0FQG0ZZ would move it to 405-407.
- 54390: low confidence. Exstrophy-associated epispadias repair coded as Repair urethra + Repair penis. Use Supplement if graft or flap tissue is used.
- 54430: no penis Bypass in PCS, so the corporo-spongiosal shunt = Drainage of penis.
- 55650: typical dx C637 (seminal vesicle malignancy, 715-716) vs cyst Q554 (717-718). The typical indication in Medicare is uncertain.
