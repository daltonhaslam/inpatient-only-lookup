# Pass B, batch m03: codes for a second look

- 32488: I used Resection of the whole lung (0BTK/0BTL) for the remaining lobes. The other reading is Resection of each remaining lobe. Both group to 163-165.
- 32503/32504: the rib count is a judgment call. I used 3 or more ribs (0PB20ZZ, Excision because rib segments are removed); 1 to 2 ribs fits some cases. On 32504 I coded the reconstruction as Supplement of chest wall with synthetic substitute; Replacement of ribs is an alternative reading.
- 32540: the empyema sac is cut out, so I used Excision of pleura. Extraction (the decortication root) is the other option. PCS has no Resection value for pleura.
- 32650: chemical pleurodesis (talc, 3E0L4GC) groups to 166-168 and mechanical abrasion (Destruction of pleura) groups to 163-165. Which one is typical drives the family. The malignant effusion is coded to the primary cancer, because J91.0 is a "code first" code and can't be principal.
- 32653: Extirpation from the pleural cavity (0WC9/0WCB 4ZZ) is non-OR, so the case groups medical (traumatic hemothorax goes to 199-201). Check whether a coder would code clot evacuation as Drainage instead. Both appear to be non-OR.
- 32672: the bilateral body value 0BBM4ZZ is non-OR in v44 and groups medical (COPD 190-192). The open bilateral code 0BBM0ZZ and the unilateral 4ZZ codes group to 163-165. This looks like a grouper quirk worth confirming. If staged unilateral VATS LVRS is the typical case, the unilateral sets apply.
- 32815: I coded stump closure as Repair of bronchus. A muscle or omental flap buttress, which is common, would add a Transfer code. I left it out.
- 32940: low confidence. This is a historic collapse/plombage operation. I coded the pneumonolysis as Release of lung, and PCS has no clean device value for the packing. The diagnosis (NTM/TB) is a guess for a near-extinct operation.
- 32997: I used approach 7 (through a double-lumen tube). If the lavage is done through a bronchoscope it is 3E1F88Z. Either way it is non-OR and groups to ILD 196-198.
- 32673: the principal diagnosis changes the family. Thymoma goes to 802-804 (blood OR) and myasthenia gravis goes to 040-042.
- 38380: a neck chyle leak after surgery (I97.89) groups to 981-983, unrelated. If the indication is chylothorax (J94.0) it goes to 163-165. I'm not sure which indication is typical for the neck approach.
- 38562/38564: low/medium confidence on the qualifier. With the diagnostic qualifier (X, staging sampling) the case groups in-MDC (749-750, 715-716, 673-675). With the non-diagnostic qualifier (Z) it groups to 987-989, unrelated. I included both as sets. 38564's typical principal diagnosis (kidney cancer) is uncertain.
- 38724: a secondary neck node principal diagnosis (C77.0) goes to 820-822. Thyroid cancer goes to 628-630, and a head and neck primary would go to 140-142. The typical diagnosis drives the family.
- 38765: I used Resection of inguinal lymphatic, reading the superficial packet as the whole inguinal body part because femoral nodes are a separate body part. With Excision plus C77.4 the case groups to 987-989, unrelated.
- 38770/38780: whether these are Resection (whole chain) or Excision is a judgment call. The typical principal diagnosis (prostate vs gyn; nodal metastasis vs testis) also changes the family.
- 39000/39010: I mapped these as drainage for mediastinitis. Exploration alone would be Inspection, and the biopsy variant would be diagnostic Excision. The family differs: 39010 Inspection goes to 163-165, while Drainage goes to 166-168.
