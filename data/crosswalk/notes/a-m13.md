# Pass A, batch m13: codes for a second look

- 55842 / 55862 — node sampling coded as diagnostic Excision of pelvic lymphatics (07BC0ZX). A coder could argue that staging sampling is not diagnostic (07BC0ZZ). The DRG is the same either way.
- 55862 / 55865 — open seed placement coded as both the med/surg Insertion of a radioactive element (0VH001Z) and the LDR brachytherapy modality code. The isotope varies (I-125 vs Pd-103). Some coders report only the radiation code; the OR lymphatic code drives the DRG either way.
- 55840-55845 — 0VT00ZE (capsule-intact qualifier) exists in FY2027. I used 0VT00ZZ as the standard radical prostatectomy code. The DRG does not change.
- 27025 — Release vs Division root operation for decompressive fasciotomy (both are indexed). The typical diagnosis, traumatic compartment syndrome (T79A21A), groups to 981-983 because 0JN codes have no MDC 21 row. The nontraumatic alternative (M79A21) groups to 500-502. Which diagnosis is typical drives the family.
- 27036 — capsulotomy (Release) vs capsulectomy (Excision) of the hip joint, plus a separately coded hip muscle release. Same family either way.
- 27054 — synovectomy coded as Excision of the hip joint. The synovium is not its own PCS body part.
- 27070 / 27071 — pelvic osteomyelitis is coded to the "other site" code (M8668). The upper-femur sets group to 498-499 and the pelvic-bone sets to 515-517.
- 27076 / 27077 — the acetabulum is a separate PCS body part from the pelvic bone. Periacetabular resection is coded as Resection of the acetabulum plus Excision (27076) or Resection (27077) of the pelvic bone. Partial vs total acetabular removal is a judgment call.
- 27120 — low confidence. This CPT spans shelf, Colonna and cup-type procedures. I coded Supplement of the acetabulum with autograft; a cup-type case would be Replacement of the acetabular surface (a different family).
- 27122 — the typical diagnosis for a Girdlestone done without a prosthesis in place is uncertain. I used septic hip arthritis.
- 27132 — this case lands in 498-499 rather than 469-470. In the v44 MDC 8 hierarchy, 498-499 ranks above 469-470, so the separately coded hardware removal from the upper femur (0QP604Z) decides the DRG. Confirm that a coder would report the hardware removal in a conversion total hip.
- 27134 / 27137 / 27138 — v44 has no 466-468 row for 0SP removal codes; they carry only 403-404 and 463-465 rows. Aseptic revisions therefore group to 463-465 (titled wound debridement/skin graft). That is the v44 table behavior, not a coding choice, but worth a reviewer's eye.
- 27137 / 27138 — the device value for the revised component (polyethylene 0 for the acetabular side, metal 1 for the femoral side) is a judgment call. The DRG does not change.
- 27158 — Medicare volume is negligible; in practice this procedure is mostly done for bladder exstrophy. The Q6410 alternative groups to 981-983.
- 27175 — traction only is non-OR (Placement section), so the case groups medically (553-554) by diagnosis. This is expected.
- 27176 / 27177 — in-situ pinning coded as Insertion (no repositioning). Open treatment coded as Reposition; it would be Insertion if no reduction was done. Same family either way.
- 27140, 27161, 27165 — the typical diagnosis for an adult Medicare patient is a judgment call (coxa plana, coxa vara). The family is 480-482 regardless.
